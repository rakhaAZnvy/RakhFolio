Portfolio pribadi Rakha Adinata Zavier

Situs ini berisi profil, proyek, pengalaman organisasi, sertifikat, dan publikasi saya. Dibuat dengan HTML, CSS, dan JavaScript biasa.

Menjalankan situs

Buka index.html di browser. Kalau memakai VS Code, situs juga bisa dijalankan lewat ekstensi Live Server.
Tidak ada proses build atau paket yang perlu di-install.

Isi folder

- index.html — halaman utama dan daftar proyek, pengalaman, sertifikat, serta publikasi.
- project/ — halaman detail proyek.
- organization/ — halaman detail pengalaman organisasi.
- css/ — gaya halaman utama dan halaman detail.
- js/ — slider, animasi, dialog gambar, dan efek logo.
- assets/ — foto, tangkapan layar proyek, logo, CV, dan file sertifikat.

Beberapa interaksi situs, seperti slider, pembesar gambar sertifikat, dan animasi logo saat area kosong diklik, dijalankan dengan JavaScript. Tautan publikasi dan unduhan sertifikat ada di bagian masing-masing pada index.html.
