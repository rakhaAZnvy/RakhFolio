VisioAttend

VisioAttend is a desktop attendance system I built for a computer vision course. It registers students, recognizes faces through a webcam, and records daily attendance. The app uses Python, Tkinter, and OpenCV, with Haar Cascade for face detection and LBPH for face recognition.

01

Overview

This project is a desktop application that replaces manual attendance with face recognition. A user registers a student with a numeric ID and name, captures face samples from the webcam, trains a recognition model, and then lets the camera identify students and record their attendance. It runs locally, and a ready-to-run build is available for Windows and macOS so it can be used without installing Python.

02

What it does

  • Register students:Add students with a numeric ID and name.
  • Capture facesTake face images from the webcam as training samples.
  • Train the modelBuild an LBPH face recognition model from the captured images.
  • Track and mark attendanceRecognize faces from the webcam feed and mark daily attendance.
  • Attendance logsSave each day’s attendance as a CSV file.

04

Challenges and learnings

Face recognition with LBPH turned out to be sensitive to lighting. In testing, accuracy dropped to 0% under low-light conditions, which showed me the limits of classical computer vision methods compared with deep learning approaches. The project taught me how to build a complete computer vision pipeline, from data capture and training to real-time recognition, and how to report experimental results honestly, including the ones that fail.
