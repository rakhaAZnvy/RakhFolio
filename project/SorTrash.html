SorTrash

SorTrash was my first web project to use a pretrained AI model. It classifies waste from an uploaded photo or a live camera feed and returns a category with a confidence score.

01

Overview

SorTrash is a web-based application that detects the type of trash from an image the user uploads or takes, and can also detect it in real time through a live detection feature. It was my first web development project that uses AI to analyze different types of trash.

02

What it does

  • Classify an imageUpload a photo or use the camera, and the app returns the trash category with a confidence score.
  • Live trackingReal-time detection from the camera feed.
  • DashboardTracks classification history, such as total scans, scans this week, the most common category, and the category distribution.
  • Disposal tipsEach result comes with a short tip on how to dispose of that type of waste.
03

My role

  • Project managerPlanning, team management, monitoring progress and performance, and quality control.
  • Quality AssuranceTested the website, reported bugs, and checked that its features worked as intended.
  • Front-end developerHelped build the front end and fixed some front-end issues.
  • DeliveryPushed code to GitHub, helped write the paper, and deployed the app to Vercel.
04

Challenges and learnings

Some features did not run as we planned by the time the project was finished. Even so, the project taught me how to plan the general idea and layout of a project, manage a team, apply AI on a website, and see how the lifecycle of AI and software engineering plays out in a real project.
